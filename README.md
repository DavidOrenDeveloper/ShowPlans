# תוכניות בנייה – PWA לניהול וצפייה בקבצי PDF

אפליקציה עצמאית (ללא שרת וללא Firebase). כל הקבצים והנתונים נשמרים מקומית במכשיר ב-IndexedDB.
ה-Viewer מבוסס על PDF.js של Mozilla (נטען מקומית מתוך `lib/pdfjs`, בלי CDN).

## העלאה ל-GitHub Pages
1. פתחו את ה-ZIP במחשב (חשוב: לחלץ, לא להעלות את ה-ZIP עצמו).
2. ב-GitHub: New repository (למשל `plans`), ציבורי או פרטי (Pages בפרטי דורש חשבון בתשלום).
3. Add file ← Upload files: גררו את **כל התיקיות והקבצים** מתוך התיקייה שחולצה
   (`index.html`, `sw.js`, `manifest.webmanifest`, `css`, `js`, `lib`, `icons`).
   אם ההעלאה בדפדפן מגבילה כמות קבצים, העלו בכמה מנות, או השתמשו ב-git.
4. Settings ← Pages ← Source: `Deploy from a branch`, Branch: `main` / root ← Save.
5. אחרי דקה-שתיים תקבלו כתובת: `https://<user>.github.io/<repo>/`.

## התקנה בטלפון
- **אייפון (Safari):** פתחו את הכתובת ← כפתור שיתוף ← "הוסף למסך הבית".
- **אנדרואיד (Chrome):** פתחו את הכתובת ← תפריט ⋮ ← "התקן אפליקציה".

**חשוב:** האחסון של האפליקציה המותקנת נפרד מהאחסון של הדפדפן (בעיקר באייפון).
התקינו קודם, ורק אז העלו תוכניות. בצעו "ייצוא פרויקט" (גיבוי) באופן קבוע.

## עדכון גרסה
אחרי שינוי קבצים: `python3 tools/make-sw.py 1.0.1` (מעדכן את `sw.js`), והעלו מחדש.
ללא העלאת מספר גרסה חדש ה-Service Worker ימשיך להגיש את הגרסה השמורה.

## מבנה
- `js/db.js` IndexedDB · `js/store.js` נתונים, ייבוא, אינדוקס · `js/viewer.js` + `js/layer.js` + `js/markup.js` ה-Viewer
- `js/browser.js` מסך תיקיות · `js/backup.js` + `js/zip.js` גיבוי ושחזור · `sw.js` עבודה Offline
- מבנה נתונים: Project, Folder, Plan, Version (כל גרסה עם קובץ משלה), Markup / Measurement / Link (לפי גרסה), Calibration (לפי גרסה ועמוד), Thumbnail, TextIndex.

## מגבלות ידועות (בכנות)
- **אחסון:** המכסה נקבעת על ידי הדפדפן. Safari עלול למחוק נתוני אתר שלא הותקן אחרי כמה ימים בלי שימוש. הגיבוי הוא רשת הביטחון.
- **"פתח באמצעות":** דפדפן לא יכול להפעיל אפליקציה מסוימת או להציג את רשימת האפליקציות. הדרך האמינה היא תפריט השיתוף של המכשיר (Web Share), או הורדה.
- **מסך מלא:** באייפון (טלפון) Fullscreen API לא נתמך; האפליקציה המותקנת ממילא ללא סרגל דפדפן, ויש "תצוגה נקייה" שמסתירה סרגלים.
- **מדידות:** סקאלה 1:N מדויקת רק אם עמוד ה-PDF בגודל הדף המקורי. האפליקציה לא מנחשת – מחייבת סקאלה או כיול ידני.
- **השוואת תוכניות:** חזותית בלבד (צבעים/שקיפות/לצד-לצד) ויישור ידני. אין זיהוי שינויים אוטומטי.
- **חיפוש בתוך PDF:** רק לקבצים עם שכבת טקסט. OCR לסריקות לא קיים.
- **גיבוי:** קובץ ZIP יחיד, עד 4GB. גיבוי גדול מאוד עלול להיכשל בטלפונים עם מעט זיכרון (במקרה כזה, לגבות בחלקים).
- **שיתוף קבצים אל האפליקציה (Share Target):** מוגדר ב-manifest לאנדרואיד בלבד, לא נבדק במכשיר אמיתי.
- **CMaps:** קבצי פונטים מיוחדים לשפות אסיאתיות לא מצורפים (כדי לשמור על פחות קבצים). PDF עם פונטים שלא מוטמעים בשפות אלו עלול להיראות לא תקין.
- **Drag & Drop** עובד במחשב; במובייל יש "העבר…" בתפריט ובבחירה מרובה (לחיצה ארוכה).
